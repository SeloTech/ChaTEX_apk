ChaTEX 18.2 — TELEX + Mobile + Фоны
====================
Папки:
  src/   — читаемый исходник (его правите вы)
  dist/  — готовая защищённая сборка (это выкладывается на Firebase)
  database.rules.json — правила базы (ГЛАВНАЯ защита от самовыдачи админки/Plus)

ВЫКЛАДКА НА FIREBASE (один раз установить, дальше одна команда)
---------------------------------------------------------------
  npm install -g firebase-tools
  firebase login
  npm install
  npm run deploy

Команда `npm run deploy` сама пересобирает dist/ и выкладывает hosting + правила БД.
Если нужно руками:   node build.js && firebase deploy --only hosting,database

ВАЖНО СРАЗУ ПОСЛЕ ПЕРВОЙ ВЫКЛАДКИ
---------------------------------
Теперь админку/Plus/verified/blocked может менять только тот, у кого уже есть
права в базе. По имени пользователя права больше НЕ выдаются.
Откройте Firebase Console → Realtime Database → users → <uid вашего аккаунта>
и проверьте, что у вас стоят isSuperAdmin: true и isAdmin: true.
(Если вы раньше заходили под Rubick/Skils — они уже стоят, ничего делать не надо.)
Выдать права новому админу можно из админ-панели, либо вручную в консоли.

Plus после оплаты: liqpay-payment-server ставит premium через Admin SDK —
правила его не ограничивают, он продолжит работать.

БЕЗОПАСНОСТЬ (новое)
--------------------
Настройки → Устройства: список входов в аккаунт — название устройства, IP, страна,
время входа и последний раз в сети. Кнопка «Завершить» выкидывает устройство
(оно выйдет при следующем соединении). «Это устройство» — текущее.
Записи появляются с момента обновления: старые входы не восстановить.

Настройки → Конфиденциальность:
  • Код-пароль (4–6 цифр): запрашивается при каждом входе в приложение или
    через 1 мин / 5 мин / 15 мин / 1 час бездействия. Хранится только на этом устройстве.
  • Облачный пароль (от 4 символов, буквы/цифры/знаки): запрашивается при входе
    на новом устройстве. Можно задать подсказку (не должна содержать сам пароль).
    Если пароль забыт и нет доверенного устройства — обращение в поддержку.

Правила БД: user_sessions/{uid} и user_security/{uid} доступны только владельцу.
Выкладка: npm run deploy (правила и сборка уходят вместе).

ОГРАНИЧЕНИЯ (важно понимать)
  • Код-пароль и облачный пароль — проверка в приложении. Они защищают от открытия
    интерфейса, но не от человека с доступом к инструментам разработчика в браузере.
  • «Завершить» мгновенно выкидывает устройство, если оно открыто. Устройство, которое
    офлайн, выйдет только когда снова подключится. Полный отзыв всех токенов даёт
    Admin SDK (revokeRefreshTokens) — в этой версии не сделано (потребовало бы функцию).
  • IP и страна определяются сторонним сервисом ipapi.co при входе.
