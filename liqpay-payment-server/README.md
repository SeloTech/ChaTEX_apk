# Сервер оплаты Premium через LiqPay (без Firebase Blaze)

Принимает оплату картой (любой страны) в гривне и включает Premium
пользователю в базе ChaTEX. Работает точно так же, как уже настроенный
у вас `email-admin-server` — просто ещё один маленький Node-сервер.

## Шаг 1. Завести аккаунт LiqPay и получить ключи

1. Зарегистрируйтесь на https://www.liqpay.ua (нужна украинская карта или
   ФОП/самозанятость для реального вывода денег себе на счёт — если
   ИНН/ФОП ещё нет, можно начать с песочницы, см. ниже).
2. В личном кабинете: **Меню → Магазины/API** → создайте магазин →
   скопируйте **Public key** и **Private key**.
3. Для тестов без реальных денег включите режим песочницы (sandbox) —
   в LiqPay это отдельные тестовые ключи в том же кабинете.

## Шаг 2. Задеплоить сервер на Render.com (бесплатно, как и первый сервер)

1. Залейте папку `liqpay-payment-server/` в репозиторий на GitHub
   (можно в тот же репозиторий, что и `email-admin-server`, отдельной
   папкой — просто на Render это будет второй, отдельный Web Service).
2. В Render: **New → Web Service** → выберите репозиторий →
   **Root Directory:** `liqpay-payment-server`.
3. Настройки:
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
   - **Instance Type:** Free
4. В разделе **Environment** добавьте переменные — их можно взять прямо из
   файла `.env.example` рядом с этим README (туда уже вписаны присланные
   вами тестовые sandbox-ключи LiqPay, ими можно сразу проверить весь
   процесс покупки без реальных денег):
   - `FIREBASE_SERVICE_ACCOUNT` — тот же JSON, что и в первом сервере
   - `FIREBASE_DATABASE_URL` — `https://chatex-8b404-default-rtdb.firebaseio.com`
   - `ALLOWED_ORIGIN` — адрес вашего сайта, например `https://chatex-8b404.web.app`
   - `LIQPAY_PUBLIC_KEY` = `sandbox_i38801990261`
   - `LIQPAY_PRIVATE_KEY` = `sandbox_pLBZ2gEoCv5bGbee9j5jjl433Y5MsLPrWrHJkZEh`
   - `LIQPAY_SANDBOX` = `1` (это тестовый режим — деньги не списываются;
     когда всё проверите, зайдите в личный кабинет liqpay.ua, получите
     БОЕВЫЕ ключи и замените ими эти два, а `LIQPAY_SANDBOX` удалите)
   - `PREMIUM_PRICE_UAH` — `50` (или другая цена на ваше усмотрение)
5. Deploy. Скопируйте адрес вида `https://chatex-payments.onrender.com`.
6. **Важно:** зайдите в Environment ещё раз и добавьте
   `SERVER_URL = https://chatex-payments.onrender.com` (тот самый адрес,
   который вам выдал Render) — сервису нужно знать свой собственный
   публичный адрес, чтобы сказать LiqPay, куда слать подтверждение оплаты.

⚠️ Как и первый сервер, бесплатный план Render "засыпает" после простоя —
первая оплата после сна пользователь подождёт на 20-30 секунд дольше.

## Шаг 3. Подключить сервер на сайте

Откройте `js/01-config-state.js` и впишите адрес из Render:

```js
const LIQPAY_SERVER_URL = 'https://chatex-payments.onrender.com';
```

Задеплойте сайт как обычно: `firebase deploy --only hosting`.

## Как проверить, что всё работает

1. В режиме `LIQPAY_SANDBOX=1` нажмите "Купить Premium" в настройках —
   откроется страница LiqPay с тестовой формой оплаты (реальные деньги
   не списываются).
2. После "оплаты" в песочнице проверьте в Firebase Console:
   `users/{ваш uid}/premium` должно стать `true`, а
   `payments/{ваш uid}/...` — появится запись со `status: "success"`.
3. Когда всё сходится — уберите `LIQPAY_SANDBOX` (или поставьте `0`) и
   замените ключи на боевые (не sandbox) из личного кабинета LiqPay.

## Почему нельзя было принимать именно рубли с выводом в гривны

Российский эквайринг (ЮKassa, CloudPayments, Робокасса и т.п.) не может
зачислять деньги на украинский счёт — платёжные системы РФ и Украины
сейчас разъединены на уровне банковской инфраструктуры, это не вопрос
настроек кода. LiqPay решает это иначе: цена показывается сразу в
гривне (UAH), а платить может любая карта мира — то есть "чтобы вообще
каждый мог купить" сохраняется, просто через одну понятную валюту вместо
попытки смешать рубли и гривны в одном платеже.
